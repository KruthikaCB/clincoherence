# ClinCoherence Frontend

Next.js 14 frontend application for the ClinCoherence multi-turn clinical verification chatbot.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS
- **Testing:** Playwright

## Prerequisites
- Node.js 22+ & npm
- Chromium browser binary (managed via Playwright)

## Available Scripts

In the `frontend` directory, you can run:

```bash
# Start development server on http://localhost:3000
npm run dev

# Run Next.js production build
npm run build

# Start production server
npm run start

# Run ESLint check
npm run lint

# Run Playwright end-to-end tests (starts web server automatically)
npm test

# Run Playwright tests with UI mode
npm run test:ui
```
